## 📖 About

Welcome to **Courses Handbooks**, the companion repository for the courses on the [**Asadullah AI**](https://www.youtube.com/@aiasadullah) YouTube channel.

Every course I publish comes with a structured, easy-to-follow handbook so you can:

- ✅ Revise key concepts quickly without rewatching videos
- ✅ Keep commands, code snippets, and cheat sheets at your fingertips
- ✅ Learn at your own pace, online or offline
- ✅ Use them as a reference long after finishing the course

All handbooks are **free** and will be added here as new courses are released.

## 🚀 How to Use This Repository

**Option 1: Download a single handbook**

1. Click the PDF file in the file list above.
2. Press the **Download raw file** button.

**Option 2: Clone the whole repository**

```bash
git clone https://github.com/AsadullahShehbaz/Courses-Handbooks.git
cd Courses-Handbooks
```

**Option 3: Stay updated**

Click **⭐ Star** and **👁 Watch** on this repository to get notified whenever a new handbook is added.
